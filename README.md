## About

Latest version of my resume, based on Adrien Friggeri's [CV][af-cv].

Typesetted in Proxima Nova, Ostrich Sans. Colors inspired by Monokai.

Uses TikZ for the header, XeTeX and fontspec to embed fonts, biblatex to print publications and textpos for the aside.

## Notes

On my machine, the header does not get properly built the first time. Thus when compiling the resume from scratch it must be compiled twice for the correct result.
